BÀI THỰC HÀNH LAYOUT · ASP.NET CORE MVC

NxbLesson14

Làm theo các phần trong PDF: Layout, ViewImports, ViewStart, Area, ghép HTML template và CRUD bằng Entity Framework. Tên project được đổi thành NxbLesson14.

Chạy bản đã làm: Giải nén toàn bộ ZIP → mở NxbLesson14.sln → chờ khôi phục NuGet → chọn profile http → nhấn Ctrl+F5. Trang chủ: http://localhost:5140/; Admin: http://localhost:5140/Admin.

1. Chuẩn bị Visual Studio

  1. Mở Visual Studio Installer, chọn Modify ở Visual Studio 2022.
  2. Tích workload ASP.NET and web development.
  3. Trong Individual components, bảo đảm có SDK .NET 8 và SQL Server Express LocalDB. Bản làm sẵn dùng .NET 8.

2. Chọn đúng template project

  1. Trong Visual Studio chọn Create a new project.
  2. Lọc C# → Windows → Web; tìm tên ASP.NET Core Web App (Model-View-Controller).
  3. Chọn template này và nhấn Next.

3. Xem Layout, ViewImports và ViewStart

Phần này ứng với trang 1–6 của PDF. Mở ba file:

FileVai trò
Views/Shared/_Layout.cshtmlChứa cấu trúc HTML dùng chung: head, menu, footer, CSS và JavaScript. @RenderBody() đặt nội dung view vào layout.
Views/_ViewImports.cshtmlKhai báo namespace và TagHelpers để dùng asp-controller, asp-action, asp-for.
Views/_ViewStart.cshtmlChọn layout mặc định cho các view trong thư mục Views.
@using NxbLesson14
@using NxbLesson14.Models
@addTagHelper *, Microsoft.AspNetCore.Mvc.TagHelpers

Layout có các vùng tùy chọn: @await RenderSectionAsync("Css", required: false) trong head và @await RenderSectionAsync("Scripts", required: false) trước khi kết thúc body. View muốn thêm CSS hoặc script khai báo @section Css / @section Scripts.

4. Tạo và chọn layout _main

  1. Nhấp phải Views/Shared → Add → New Item hoặc Add → View.
  2. Chọn item Razor Layout hoặc Razor View - Empty để tạo file _main.cshtml.
  3. Thêm head, menu, CSS/JS Bootstrap và một @RenderBody() vào layout.
  4. Một view dùng riêng layout có thể khai báo Layout = "_main"; ở đầu file.
  5. Để dùng chung cho trang người dùng, sửa Views/_ViewStart.cshtml:
@{
    Layout = "_main";
}

Trong bản hoàn chỉnh, _main đã được thay bằng Bistup ở bước 8. Bản Bootstrap của bước này được giữ ở _BootstrapMain.cshtml; mở /Home/LayoutDemo để thử phần layout và section.

5. Tạo Area Admin

  1. Nhấp phải project → Add → New Scaffolded Item.
  2. Chọn MVC Area → Add.
  3. Nhập tên Admin.
  4. Trong Areas/Admin/Views, tạo thư mục Shared, rồi thêm layout Admin.cshtml.
  5. Trong Areas/Admin/Views, tạo _ViewImports.cshtml có cùng nội dung như bước 3.
  6. Tạo _ViewStart.cshtml cho riêng Area:
@{
    Layout = "/Areas/Admin/Views/Shared/Admin.cshtml";
}

PDF có chỗ ghi “Admins”, nhưng các route và cấu trúc cuối dùng “Admin”. Bản làm sẵn dùng thống nhất Admin.

6. Tạo Dashboard và Category

  1. Nhấp phải Areas/Admin/Controllers → Add → Controller.
  2. Chọn template MVC Controller - Empty; đặt tên DashboardController.
  3. Thêm thuộc tính [Area("Admin")] trước khai báo class.
  4. Tạo action Index trả về View().
  5. Nhấp phải action Index → Add View; chọn tên Index, template Empty (without model), tích Use a layout page.
  6. Để trống ô layout khi đã có _ViewStart, hoặc trỏ đến Admin.cshtml.
  7. Lặp lại với CategoryController và view Category/Index.cshtml.
namespace NxbLesson14.Areas.Admin.Controllers;

[Area("Admin")]
public class DashboardController : Controller
{
    public IActionResult Index() => View();
}

Bản cuối đã mở rộng Dashboard thành bốn ô thống kê thật và Category thành trang CRUD.

7. Cấu hình route của Area

Trong Program.cs, đặt route Area trước route trang người dùng:

app.MapControllerRoute(
    "areas",
    "{area:exists}/{controller=Dashboard}/{action=Index}/{id?}");

app.MapControllerRoute(
    "default",
    "{controller=Home}/{action=Index}/{id?}");

Build project. /Admin gọi Dashboard, /Admin/Category gọi Category trong Area.

8. Ghép template Bistup cho trang người dùng

  1. Giải nén template Bistup như mẫu trong PDF.
  2. Đưa ảnh vào wwwroot/images, CSS vào wwwroot/css, JavaScript vào wwwroot/js. Giữ cấu trúc thư mục font để CSS tải đúng.
  3. Lấy phần HTML khung của template đặt vào Views/Shared/_main.cshtml.
  4. Giữ header, menu và footer trong layout; thay vùng banner/nội dung bằng @RenderBody().
  5. Đưa phần banner và nội dung giữa trang vào Views/Home/Index.cshtml.
  6. Sửa đường dẫn tài nguyên: ~/css/layout.css, ~/js/jquery.min.js, ~/images/demo/348x261.png. Với background CSS inline dùng /images/demo/backgrounds/01.png.
  7. Đổi menu sang các liên kết asp-controller / asp-action và build lại.

Bản làm sẵn đã tách header/footer thành partial view _Header.cshtml, _Footer.cshtml. Nội dung hero và các khối giới thiệu/ảnh được giữ theo mẫu Bistup trong tài liệu.

9. Ghép AdminLTE 3 cho Admin

  1. Dùng AdminLTE 3 như phần bài tập tự làm.
  2. Chép các tài nguyên cần dùng trong dist và plugins vào wwwroot.
  3. Dùng khung HTML của AdminLTE cho Areas/Admin/Views/Shared/Admin.cshtml.
  4. Đặt @RenderBody() bên trong vùng content-wrapper → content.
  5. Nạp CSS Font Awesome + AdminLTE; cuối body nạp jQuery, Bootstrap bundle và AdminLTE JS.
  6. Giữ các menu phù hợp với bài: Dashboard, Category, Product, Blog và Banner.

10. Tách menu thành ViewComponent

Tạo ViewComponents/NavLeftViewComponent.cs với phương thức Invoke() trả về View(). Đặt HTML sidebar tại Areas/Admin/Views/Shared/Components/NavLeft/Default.cshtml.

@await Component.InvokeAsync("NavLeft")

Bản hoàn chỉnh còn tách AdminHeader và AdminFooter thành ViewComponent. Khi chuyển trang quản trị, menu tương ứng được đánh dấu đang chọn.

11. Tạo model và DbContext

Cài qua Tools → NuGet Package Manager → Manage NuGet Packages for Solution: Microsoft.EntityFrameworkCore.SqlServer, Microsoft.EntityFrameworkCore.Design. Bản làm sẵn thêm provider SQLite để chạy thử khi chưa có SQL Server.

ModelCác trường
CategoryId, Name, Status, CreatedDate, Image, Description
ProductId, Name, Price, salePrice, Status, CategoryId, CreatedDate, Image, Description
BannerId, Name, Status, Prioty, Image, Description
BlogId, Name, Status, CreatedDate, Image, Description

Tạo Data/NxbLesson14Context.cs; khai báo bốn DbSet, khóa chính tự tăng, Name unique, các độ dài 100/350 và khóa ngoại Product → Category. Thuộc tính C# SalePrice được ánh xạ vào cột salePrice; giữ tên cột Prioty đúng đề.

Trong appsettings.json đã có connection string đến NxbLesson14Db qua SQL Server LocalDB. Program.cs đăng ký DbContext và gọi phần tạo CSDL/dữ liệu mẫu ở lần chạy đầu.

12. Tạo CRUD cho bốn thực thể

  1. Nhấp phải Areas/Admin/Controllers → Add → New Scaffolded Item.
  2. Chọn MVC Controller with views, using Entity Framework.
  3. Chọn Model class tương ứng và Data context class là NxbLesson14Context.
  4. Controller name: lần lượt CategoryController, ProductController, BannerController, BlogController.
  5. Chọn layout Admin; kiểm tra namespace, thuộc tính [Area("Admin")] và vị trí các view sau khi sinh.
  6. Bổ sung kiểm tra tên trùng, khoảng trắng, giá và khóa ngoại. Các view danh sách dùng bảng Bootstrap 4; nút thao tác dùng icon Font Awesome.

Trong bản làm sẵn, bốn controller và toàn bộ Index/Create/Edit/Details/Delete đã hoàn thành. Product có danh sách chọn Category. Mỗi form có validation, thông báo lỗi và nút quay lại; xóa có trang xác nhận.

14. Nếu máy chưa có SQL Server

Để chạy nhanh, trong appsettings.json đổi "DatabaseProvider": "SqlServer" thành "DatabaseProvider": "Sqlite". File CSDL được tự tạo khi chạy. Khi đã cài LocalDB, có thể đổi lại SqlServer; hai provider dùng hai CSDL riêng.

Nếu dùng SQL Server Express, sửa server trong connection string thành .\SQLEXPRESS (trong JSON phải viết .\\SQLEXPRESS). Xem chi tiết ở README.md.
